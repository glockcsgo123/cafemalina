## БЛОК 2 — Карточка блюда (модальное окно)
> 🆕 Новая фича. Зависит от блока 1.

### 2.1 Компонент `<MenuItemModal />`
Создать `src/components/menu/MenuItemModal.tsx`:

**Открытие:** клик на карточку блюда (на фото или на название) — НЕ на кнопку «В корзину»
Кнопка «В корзину» добавляет в корзину БЕЗ открытия модального окна (поведение не меняется)

**Содержимое модального окна:**
- Фото блюда — крупное, на всю ширину верхней части (aspect-ratio 4/3), с возможностью открыть в полном размере (лайтбокс)
- Название блюда — крупный заголовок
- Состав/описание — полный текст из поля `description` (не обрезанный)
- Вес — если есть поле `weight`
- Варианты размеров — кнопки-переключатели если есть `variants` (32 см / 40 см)
- Цена — крупно, обновляется при смене варианта
- Кнопка «В корзину» — добавляет выбранный вариант, закрывает модалку
- Кнопка закрытия × в правом верхнем углу
- Закрытие по клику на backdrop и по клавише Escape

**Лайтбокс для фото:**
- Клик на фото в модалке → фото открывается на весь экран поверх всего
- Закрытие по клику/Escape
- Можно реализовать через второй `<Dialog>` или CSS `position: fixed`

**Интеграция:**
- В компоненте карточки `src/components/menu/MenuCard.tsx` (или как он называется) обернуть фото и название в `<button onClick={() => openModal(item)}>`
- Использовать `shadcn/ui Dialog` для модального окна
- Состояние через `useState` в родительском компоненте страницы меню

**Пример структуры модалки:**
```
┌─────────────────────────────────┐

│  сыр моцарелла, соус фирменный  │
```

### 8.2 API Routes
```
GET    /api/menu           — список блюд (публичный)
POST   /api/menu           — добавить блюдо (🔒 ADMIN_PASSWORD)
PUT    /api/menu/[id]      — обновить блюдо (🔒 ADMIN_PASSWORD)
DELETE /api/menu/[id]      — удалить блюдо (🔒 ADMIN_PASSWORD)
POST   /api/upload         — загрузить фото в /public/images/ (🔒)
GET    /api/orders         — список заказов (🔒)
POST   /api/orders         — создать заказ (публичный, из чекаута)
PUT    /api/orders/[id]    — сменить статус заказа (🔒)
POST   /api/auth           — логин, ставит httpOnly cookie
POST   /api/auth/logout    — логаут, удаляет cookie
```

### 8.3 Защита роутов
- `src/middleware.ts`: маршруты `/admin/*` → проверить cookie `admin_token` → иначе redirect `/admin/login`
