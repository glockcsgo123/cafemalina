## БЛОК 3 — Баг админки: поле «Минимальный заказ»

**Проблема:** в разделе «Настройки» админки поле минимального заказа показывает 0 и не стирается при вводе — нельзя изменить значение.

**Файл:** `src/app/admin/settings/page.tsx` или компонент настроек.

**Причина:** скорее всего `value={settings.minOrderAmount}` без правильного handler'а, или `defaultValue` вместо `value`, или число 0 блокирует очистку поля.

**Исправление:**
```tsx
// Неправильно — число 0 не даёт очистить поле:
<input type="number" value={settings.minOrderAmount} onChange={...} />

// Правильно — хранить как строку в локальном стейте:
const [minOrder, setMinOrder] = useState(String(settings.minOrderAmount ?? ""))

<input
  type="number"
  value={minOrder}
  onChange={(e) => setMinOrder(e.target.value)}
  onBlur={() => {
    const val = parseInt(minOrder) || 0
    updateSettings({ minOrderAmount: val })
  }}
  placeholder="0"
  min="0"
/>
```

**Дополнительно** — проверить все числовые поля в настройках (минимальный заказ, бесплатная доставка от, время доставки):
- Все числовые поля должны работать по той же схеме — локальный string-стейт
- При blur сохранять как число
- Кнопка «Сохранить» должна сохранять все поля сразу через PUT /api/settings
